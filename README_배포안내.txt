체납관리단 전화상담 도우미 PWA (v3 원본 기능 유지)

1. 압축파일을 풀고 폴더의 index.html, manifest.webmanifest, sw.js, vercel.json, icons 폴더를 그대로 유지합니다.
2. Vercel에 새 프로젝트로 이 폴더를 배포합니다. Framework Preset은 Other, Root Directory는 프로젝트 폴더, 빌드 명령은 비워 둡니다.
3. 배포 후 제공되는 https://...vercel.app 주소를 안드로이드 크롬에서 엽니다.
4. Chrome 메뉴 > 앱 설치 또는 홈 화면에 추가를 선택합니다.
5. 설치 및 최초 접속은 인터넷이 필요하며, 이후 정상적으로 캐시되면 오프라인 사용 가능합니다.

주의: 공개 URL을 아는 누구나 열람할 수 있습니다. 민원인 개인정보를 넣지 마십시오. 기관 업무용 배포 승인 및 매뉴얼/FAQ 법령 검토 후 배포하십시오.
Vercel Hobby 무료 플랜의 기관 업무 사용 적합성/이용 약관도 확인하십시오.
